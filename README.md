**Heart Disease Prediction System**
**Overview**
The Heart Disease Prediction System is a Machine Learning-based web application designed to predict the likelihood of heart disease using patient medical data. The system analyzes various health parameters and provides prediction results to assist in early diagnosis and healthcare decision-making.

**Features**
User-friendly web interface
Heart disease risk prediction using Machine Learning
Real-time prediction results
Data preprocessing and feature analysis
Accurate and efficient prediction model
Easy deployment using Flask

Dataset

The project uses the Heart Disease Dataset containing medical attributes such as:
Age
Sex
Chest Pain Type
Resting Blood Pressure
Cholesterol Level
Fasting Blood Sugar
Maximum Heart Rate
Exercise-Induced Angina
ST Depression
Number of Major Vessels
Thalassemia
